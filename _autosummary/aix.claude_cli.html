aix.claude_cli¶

A chat backend that runs prompts through the Claude Code CLI (claude -p).

With a Claude subscription and the CLI installed, claude -p answers prompts without an API key, billed to the subscription. Use a model id with the claude-cli/ prefix and aix.chat() / aix.complete() route it here instead of to LiteLLM:

>>> from aix import chat
>>> chat("Say hi in one word.", model="claude-cli/haiku")
'Hi!'

The CLI exposes no sampling controls, so temperature, max_tokens, seed, stream and the like raise ValueError instead of being ignored in silence. The cost the CLI reports is on Completion.raw["total_cost_usd"] (see claude_cli_cost()).

Notes

ANTHROPIC_API_KEY and ANTHROPIC_AUTH_TOKEN are removed from the child environment (the CLI would otherwise bill them, not the subscription); --bare is never used, since it skips the keychain read that finds the subscription login; the call runs in a fresh private temporary folder with no tools, MCP servers, slash commands or session persistence.
